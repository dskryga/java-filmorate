# Film Recommendation Application

Веб-приложение для выбора фильмов с социальными функциями, разработанное на Java Spring Boot.

## 🎯 Функциональность

### 🎬 Управление фильмами
- Добавление и обновление информации о фильмах
- Поиск фильмов по ID
- Лайки/дизлайки фильмов
- Поиск популярных фильмов (по количеству лайков)
- Поиск фильмов по названию или режиссеру
- Фильтрация по режиссеру с сортировкой по лайкам или году выпуска
- Удаление фильмов

### 👥 Управление пользователями
- Регистрация и обновление профилей
- Просмотр списка всех пользователей
- Поиск пользователей по ID
- Система друзей (добавление/удаление)
- Просмотр списка друзей
- Поиск общих друзей
- Удаление пользователей

### 📝 Отзывы на фильмы
- Создание и обновление отзывов
- Просмотр отзывов о фильме
- Лайки/дизлайки отзывов
- Поиск отзывов по ID

### 🎭 Дополнительные возможности
- Управление жанрами фильмов
- Возрастные рейтинги (MPA)
- Управление режиссерами

## 🛠 Технологии

- **Java 11**
- **Spring Boot** - основной фреймворк
- **JDBC** - работа с базой данных
- **Maven** - управление зависимостями
- **Lombok** - сокращение шаблонного кода
- **JUnit** - модульное тестирование

## 🚀 API Endpoints

### Пользователи
- `POST /users` - создание пользователя
- `PUT /users` - обновление пользователя  
- `GET /users` - список всех пользователей
- `GET /users/{id}` - поиск по ID
- `PUT /users/{id}/friends/{friendId}` - добавить в друзья
- `DELETE /users/{id}/friends/{friendId}` - удалить из друзей
- `GET /users/{id}/friends` - список друзей
- `GET /users/{id}/friends/common/{otherId}` - общие друзья

### Фильмы
- `POST /films` - добавление фильма
- `PUT /films` - обновление фильма
- `GET /films` - список всех фильмов
- `GET /films/{id}` - поиск по ID
- `PUT /films/{id}/like/{userId}` - лайк фильма
- `DELETE /films/{id}/like/{userId}` - удалить лайк
- `GET /films/popular` - популярные фильмы
- `GET /films/search` - поиск по названию/режиссеру

### Отзывы
- `POST /reviews` - создать отзыв
- `PUT /reviews` - обновить отзыв
- `GET /reviews` - отзывы о фильме
- `GET /reviews/{id}` - отзыв по ID
- `PUT /reviews/{id}/like/{userId}` - лайк отзыва
- `PUT /reviews/{id}/dislike/{userId}` - дизлайк отзыва

## 📋 Требования к данным

### Пользователь:
- Логин (не может содержать пробелы)
- Email (валидный формат)
- Дата рождения (не в будущем)

### Фильм:
- Название (не пустое)
- Описание (максимум 200 символов)
- Дата выпуска (не раньше 28.12.1895)
- Продолжительность (положительная)

## 🧪 Тестирование

В проекте предоставлена коллекция Postman для тестирования всех endpoints, включая:
- Тесты создания и валидации пользователей
- Тесты системы друзей
- Тесты управления фильмами и лайками
- Тесты обработки ошибок

Для запуска тестов используйте предоставленную коллекцию Postman с предварительно настроенными переменными.
